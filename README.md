## Ada catalog and SPARK proofs

[Ada-Algorithms](https://github.com/RobertBoettcherSF/Ada-Algorithms) is the consolidated catalog: one folder per algorithm, grouped by topic and level (`<topic>/Ada/…`, `<topic>/SPARK2/…`, and the other SPARK levels). MIT. Its README describes the folders as educational sheets, and names larger projects that stay outside it: Logistics, Rule-30, and Blauer Sand / `lern_engine`.

[`TOPICS.md`](https://github.com/RobertBoettcherSF/Ada-Algorithms/blob/main/TOPICS.md) counts **12,703** files in the topic tree (Ada 6,024, SPARK1 0, SPARK2 6,218, SPARK3 16, SPARK4 445) and **1,838** source sheet repositories walked.

The headline table is generated by `make proof-index`. The monorepo README says those numbers are written by that command from the build and proof records. Last published regeneration: **2026-10-11**.

| Record | Folders |
| --- | ---: |
| Algorithm folders (duplicates counted once) | 1838 |
| Silver-proven, non-trivial (not stubs, more than 3 checks) | 522 |
| Training-ready under rule v1 (2026-10-11) | 91 confirmed + 0 pending re-score |
| Training-ready under the previous rule | 321 |
| Open findings (`tools/vv/findings.csv`) | 12 |
| Implementation candidates (stubs; `docs/IMPLEMENT.md`) | 129 |

In that README, Silver means proved free of run-time errors. The same README treats a correct answer as a separate claim. Training-ready under rule v1 is the stricter published bar (held-out tests, a proof pass, clean GNAT 12 and GNAT 14 builds, and the other gates in [`docs/VV.md`](https://github.com/RobertBoettcherSF/Ada-Algorithms/blob/main/docs/VV.md)). Per-folder rows are in [`PROOFS.md`](https://github.com/RobertBoettcherSF/Ada-Algorithms/blob/main/PROOFS.md). Open hard problems are in [`docs/HANDOVER.md`](https://github.com/RobertBoettcherSF/Ada-Algorithms/blob/main/docs/HANDOVER.md).

Commits from the monorepo's creation on 2026-09-24 through 2026-10-11 are the public record of the move into topic folders and of the proof, rescore, and handover sessions. The 2026-09-20 scores on this page (connected-component labeling, median filtering, Cooley–Tukey FFT, PN-Counter, and the other featured `Ada-SPARK-*` sheets) belong to repositories that are now archived. The index above is the later measurement.
